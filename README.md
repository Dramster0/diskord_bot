# Discord Bot — модульная структура

## Структура проекта

```
discord-bot/
├── bot.py              ← запускаешь этот файл, он загружает модули
├── cogs/
│   ├── __init__.py
│   └── music.py        ← музыка (play, skip, queue и т.д.)
├── .env                 ← сюда вставляешь токен (создать самому по образцу .env.example)
├── .env.example
└── requirements.txt
```

Когда захочешь добавить новую функцию (модерация, приветствия и т.п.) —
просто попроси создать новый файл вроде `cogs/moderation.py` и добавить
`"cogs.moderation"` в список `INITIAL_COGS` внутри `bot.py`. Музыка при
этом не трогается вообще.

## Установка (Windows)

1. Установи Python 3.10+ (при установке отметь галочку "Add python.exe to PATH")
2. Установи FFmpeg и добавь его в PATH (см. предыдущие инструкции)
3. Открой командную строку в папке проекта и выполни:
   ```
   pip install -r requirements.txt
   ```

## Настройка токена

1. Скопируй файл `.env.example` и переименуй копию в `.env`
2. Открой `.env` и вставь свой токен после знака `=`, без кавычек и пробелов:
   ```
   DISCORD_TOKEN=твой_настоящий_токен_сюда
   ```
3. Файл `.env` никогда никому не показывай и не выкладывай в открытый доступ

## Запуск

```
python bot.py
```

Если всё правильно — в консоли появится:
```
Загружен модуль: cogs.music
Бот запущен как ИмяТвоегоБота#1234
Синхронизировано 7 слэш-команд
```

## Команды

- `/play <название или ссылка>` — включить трек или добавить в очередь
- `/skip` — пропустить текущий трек
- `/pause` / `/resume` — пауза / продолжить
- `/queue` — показать очередь
- `/stop` — остановить и очистить очередь
- `/leave` — выйти из голосового канала

## Приглашение бота на сервер

OAuth2 → URL Generator → Scopes: `bot`, `applications.commands`
Permissions: Connect, Speak, Send Messages, Read Message History, Use Slash Commands
